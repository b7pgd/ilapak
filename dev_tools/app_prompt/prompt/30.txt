1. BACA KONTEKS TERLEBIH DAHULU

Baca seluruh percakapan dan gunakan hasil investigasi sebelumnya.

Pahami:

- bug / fitur yang diminta
- expected behavior
- actual behavior
- file yang disebut user
- function / component yang sudah diketahui
- route yang sudah diketahui
- flow yang sudah ditemukan
- constraint user
- hasil search sebelumnya

Jangan mengulang search yang sudah dilakukan tanpa alasan.

Jika source yang sudah tersedia cukup untuk memastikan root cause:

STOP SEARCH → LANGSUNG FIX.

---

2. PRINSIP UTAMA: SEARCH DARI YANG PALING DEKAT

Search harus mengikuti prinsip:

BUG
↓
FILE YANG DISEBUT USER
↓
FUNCTION / COMPONENT TERKAIT
↓
CALLER / CONSUMER
↓
ROUTE / API / BACKEND
↓
DEPENDENCY BERIKUTNYA JIKA MEMANG TERBUKTI DIPERLUKAN

Jangan membalik urutan menjadi:

BUG
↓
SCAN SELURUH PROJECT
↓
RIBUAN HASIL
↓
CARI-CARI YANG RELEVAN

Contoh

User mengatakan:

«"D:\b7_label\frontend\app\scanner\page.tsx" fitur scan tidak bekerja dan kamera tidak terbuka.»

Search pertama WAJIB fokus ke "scanner/page.tsx".

Jangan langsung:

- scan seluruh "D:\b7_label"
- scan seluruh backend
- scan seluruh frontend
- scan "node_modules"
- scan ".next"
- mencari semua kata "scanner"
- mencari semua route
- mencari semua "window"
- mencari semua API

Pertama pahami file Scanner.

Misalnya:

Get-Content "D:\b7_label\frontend\app\scanner\page.tsx" |
    Select-Object -First 400

atau jika file besar:

Get-Content "D:\b7_label\frontend\app\scanner\page.tsx" |
    Select-String -Pattern 'Html5Qrcode|start\(|stop\(|camera|scanner|useEffect|navigator\.mediaDevices|permission|error' |
    Select-Object Path,LineNumber,Line

Baru setelah melihat source tersebut, tentukan apakah perlu mencari:

- package "html5-qrcode"
- API backend
- route
- proxy
- HTTPS config
- permission handling
- component lain

4. JANGAN PERNAH SCAN ROOT PROJECT SECARA BLIND

Dilarang menjadikan ini sebagai default:

Get-ChildItem -Recurse -File

dari root project seperti:

D:\b7_label

lalu melakukan "Select-String" terhadap semuanya.

Ini menghasilkan noise dan tidak diperlukan.

Jika memang perlu recursive search, tentukan folder target terlebih dahulu.

Contoh:

$files = Get-ChildItem "D:\b7_label\frontend\app" -Recurse -File |
    Where-Object {
        $_.Extension -in '.tsx','.ts','.js','.jsx'
    }

Atau:

$files = Get-ChildItem "D:\b7_label\backend" -Recurse -File -Filter *.go

Jangan membuat "$files" dari seluruh project jika hanya membutuhkan satu area.

6. SEARCH BERTAHAP, BUKAN SEARCH GABUNGAN SEJAK AWAL

Gunakan progressive targeted search.

LEVEL 1 — SOURCE YANG DISEBUT USER

Jika user memberikan file spesifik:

frontend/app/scanner/page.tsx

mulai dari file tersebut.

Jika user memberikan function:

handleScan()

mulai dari function tersebut.

Jika user memberikan route:

/api/login

mulai dari source yang menangani route tersebut.

Jangan langsung mencari seluruh project.

---

LEVEL 2 — TRACE SOURCE YANG DITEMUKAN

Setelah membaca file, identifikasi dependency nyata.

Contoh:

scanner/page.tsx
↓
startScanner()
↓
html5-qrcode
↓
camera initialization

Kalau ternyata:

startScanner()
↓
fetch("/api/scanner")

baru cari:

/api/scanner

Bukan mencari seluruh kata "scanner" di project.

---

LEVEL 3 — CROSS-FILE SEARCH

Jika source menunjukkan dependency ke file lain:

page.tsx
↓
scanner.ts

baru cari / baca:

scanner.ts

Jika menunjukkan:

fetch("/api/scanner")

baru cari handler:

/api/scanner

Jika handler menunjukkan service tertentu:

ScannerService

baru trace service tersebut.

Setiap pencarian harus memiliki alasan yang berasal dari source sebelumnya.

7. SATU BATCH = SATU COPY-PASTE

Dalam satu tahap investigasi, saya hanya ingin satu batch PowerShell.

Jangan memberikan:

Command 1
jalankan

Command 2
jalankan

Command 3
jalankan

Gabungkan menjadi:

Write-Host "`n===== NAMA INVESTIGASI =====" -ForegroundColor Cyan

...

Saya copy-paste sekali.

Namun:

SATU BATCH TIDAK BERARTI HARUS SCAN BANYAK AREA.

Batch harus tetap targeted.

Contoh yang benar:

$FILE = "D:\b7_label\frontend\app\scanner\page.tsx"

Write-Host "`n===== SCANNER CAMERA LOGIC =====" -ForegroundColor Cyan

Get-Content $FILE |
    Select-String -Pattern 'Html5Qrcode|start\(|stop\(|camera|navigator\.mediaDevices|permission|useEffect' |
    Select-Object Path,LineNumber,Line

Bukan:

$files = Get-ChildItem D:\b7_label -Recurse -File

$files | Select-String -Pattern 'scanner|camera|route|fetch|api|login|...'

8. OUTPUT HARUS HEMAT DAN TERARAH

Tujuan search adalah mendapatkan informasi yang dibutuhkan, bukan membuang seluruh source ke chat.

Setiap hasil search harus jelas:

FILE → BARIS → KODE

Gunakan:

Select-Object Path,LineNumber,Line

atau output eksplisit:

"$($_.Path):$($_.LineNumber) >>> $($_.Line.Trim())"

Gunakan header:

===== SCANNER CAMERA LOGIC =====

Batasi hasil jika search terlalu luas

Gunakan:

Select-Object -First 20

atau jumlah kecil yang relevan.

Jangan menghasilkan ratusan / ribuan hasil jika beberapa baris sudah cukup.

Jika search menghasilkan terlalu banyak hasil:

Persempit pattern atau folder pada batch berikutnya.

Jangan meminta saya mengirim seluruh output noise.

10. TARGETED CONTEXT

Jika search menemukan lokasi tertentu tetapi membutuhkan context tambahan, ambil hanya block tersebut.

Contoh:

    Select-Object -Skip 140 -First 80

Jangan meminta seluruh file jika hanya membutuhkan satu function/block.

<singkat>

12. JIKA BELUM CUKUP → SEARCH BERIKUTNYA HARUS BERDASARKAN TEMUAN

Jangan menebak.

Format:

Belum cukup konteks.

Dari source ditemukan:
<temuan singkat>

Yang perlu ditemukan:
<informasi spesifik>

Jalankan:
<1 batch PowerShell>

Search berikutnya WAJIB menjelaskan hubungan dengan hasil sebelumnya.

Contoh:

scanner/page.tsx memanggil `/api/scanner`,
tetapi handler `/api/scanner` belum terlihat.

Saya perlu melihat handler tersebut.

Lalu search:

$files = Get-ChildItem "D:\b7_label\backend" -Recurse -File -Filter *.go

Write-Host "`n===== API SCANNER HANDLER =====" -ForegroundColor Cyan

$files |
    Select-String -Pattern '/api/scanner|ScannerHandler|scanner' |
    Select-Object -First 20 Path,LineNumber,Line

Bukan kembali scan seluruh project.
